# 🚀 Himanshu Yadav's Developer Portfolio

Welcome to the source code for my personal developer portfolio! This is a modern, fully responsive, and highly interactive portfolio website built from scratch using pure **HTML, CSS, and vanilla JavaScript**.

It showcases my latest projects, technical skills, education timeline, and verified certifications.

---

## ✨ Key Features

- **Modern & Responsive UI**: Looks great on desktop, tablet, and mobile devices.
- **Glassmorphism & CSS Animations**: Smooth scroll reveals (Intersection Observer), glowing highlights, and hover interactions.
- **Interactive Project Replicas**:
  - 🎨 **Netflix Clone**: Features a custom CSS-only streaming UI mockup.
  - 📝 **Notion Automation**: Features a custom CSS-only dark mode Notion replica thumbnail.
- **Dynamic Data Structure**: Skills and projects are rendered dynamically from `data/skills.js` and `data/projects.js`, making it incredibly easy to update the site without touching the HTML.
- **Certificates Grid**: Clickable certificate cards that directly open the original PDFs and images of my verified credentials.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom variables, Grid/Flexbox layouts, and keyframe animations (Zero external CSS frameworks used).
- **Vanilla JavaScript**: DOM manipulation, scroll event listeners, and Intersection Observers for performance-friendly animations.

## 🚀 Getting Started

If you want to view this portfolio locally, simply clone the repository and open `index.html` in any modern web browser!

```bash
# Clone the repository
git clone https://github.com/HimanshuYadav5998/Portfolio.git

# Navigate into the directory
cd Portfolio
```
Then, double-click `index.html` to open it.
